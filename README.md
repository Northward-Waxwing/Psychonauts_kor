## **한글패치 파일 적용법**<br>
1. 다운 받은 파일을 압축 해제하고 exe 파일과 WorkResource 폴더를 복사한 다음, 게임 폴더에 덮어씌웁니다.<br>
(게임 위치: 스팀 라이브러리 - 게임명 우클릭 - 관리 - 로컬 파일 탐색)<br>
2. 패치가 적용된 게임을 실행하고 설정에서 자막 옵션을 활성화 합니다.<br>
## **패치 전 필독사항**<br>
1. 게임 시작 시, 기존보다 로딩이 길어질 수 있습니다.<br>
2. 가끔 게임의 자체적인 버그로<br>
"로딩 중"이 깨져서 나오는 등 우회 루틴이 안 먹히는 경우가 있습니다.<br>
그럴 때 그냥 재시작하면 됩니다.<br>
시작만 넘기면 그 이후 깨지지 않으니 즐겜하십시오<br>
3. 게임이 소리만 들리고 안 켜져요!!!!!!!!!!!!!!!!!<br>
